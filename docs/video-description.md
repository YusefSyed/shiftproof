## Title
ShiftProof: Verified Volunteer Scheduling | Agents for Humans Demo

## Description
ShiftProof is a local volunteer scheduling prototype built with Strands Agents SDK for the Agents for Humans hackathon, Good Neighbor Agents track.

It plans and repairs a synthetic community-pantry schedule, independently checks every assignment, explains an infeasible case, compares hypothetical alternatives, and exports a schedule only after separate coordinator approval.

This video visualizes results from a recorded real local-model run. The volunteer data and coordinator actions are synthetic; inference waits are shortened. It is not a live browser recording. The application has not been deployed to a real pantry.
